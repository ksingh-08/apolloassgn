# 🩺 Doctor Finder – General Physicians Listing App

A modern and responsive doctor listing platform built using **Next.js 13+**. It allows users to browse and filter general physicians based on multiple criteria such as location, language, experience, and consultation fees. The admin can also add new doctors via a modal form.

## ✨ Features

- 🔍 Filter doctors by:
  - Mode of consultation: Online / In-person
  - Location: Including “Near Me” option
  - Years of experience
  - Consultation fee
  - Language spoken
  - Facilities offered
- ➕ Add doctor modal for admin
- 💻 Fully responsive and mobile-friendly
- ⚡ Fast and optimized performance with Next.js 13 App Router
